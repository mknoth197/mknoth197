# Portfolio site

Static site served via GitHub Pages.

## Local preview

```bash
cd docs
python3 -m http.server 8000
# open http://localhost:8000
```

## Publish

In GitHub: **Settings → Pages → Build and deployment**
- **Source:** Deploy from a branch
- **Branch:** `main` / `/docs`

The site will be live at: <https://mknoth197.github.io/mknoth197/>
